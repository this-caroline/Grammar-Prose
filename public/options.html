GRAMMAR PROSE · FOUNDATION PREVIEW

Your words. Your decision.

English grammar, clarity, and tone reviews run through Ollama on your computer. Drafts are never stored by this extension. Every change needs your acceptance.

Local connection

Ollama is optional while developing the foundation. Install and select a local model when you are ready to evaluate your writing. Cloud models are outside this project's scope.

Personal memory

Memory stores accept/reject counts, a “too soft” count, protected terms, and preferences you write. It does not store passages or model explanations. You can edit the JSON below, including terms and tonePreferences. Deleting memory cannot be undone unless you export it first.

Preview limitations

Complete a sentence with punctuation, then pause briefly. Check Chrome's extension keyboard shortcuts to request a review. Plain text fields have an experimental Accept action that uses Chrome's native editing command. Rich editors offer Copy suggestion. Google Docs, React-controlled inputs, and undo across real sites still require compatibility testing.

Fields are limited to 6,000 characters. Disable field lasts for the lifetime of that field; disable site persists until removed above. Passwords, non-text inputs, disabled fields, and fields marked data-grammar-prose-disabled are skipped. Chrome restricted pages cannot be reviewed.
